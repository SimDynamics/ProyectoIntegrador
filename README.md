# Proyecto Integrador

Proyecto académico 2D en **Unreal Engine 5.7**, con personajes de médico y bacteria, animaciones mediante **PaperZD** y lógica de juego organizada en Blueprints.

## Contenido del repositorio

- Blueprints de personajes, enemigo, objetos y plataformas.
- Animaciones de movimiento, ataque y derrota de los personajes.
- Menú principal, introducción y pantalla de victoria.
- Mapas, materiales, sprites y efectos de sonido.

## Abrir el proyecto

1. Descargar o clonar este repositorio.
2. Instalar Unreal Engine **5.7**, versión indicada en `ProyectoIntegrador.uproject`.
3. Instalar y habilitar una versión compatible de **PaperZD**, dependencia declarada por el proyecto.
4. Abrir `ProyectoIntegrador.uproject`.
5. Abrir el mapa `Content/Maps/Menu_principal.umap` y utilizar **Play** en el editor.

El proyecto también declara el plugin **Modeling Tools Editor Mode**. Las carpetas generadas por el editor y las compilaciones están excluidas mediante `.gitignore`.
